# Shared libraries

Área reservada para contratos e bibliotecas reutilizáveis entre produtos e
ferramentas do workspace, seguindo o padrão `shared-libs` do StartOS.

O LabsOS ainda mantém sua implementação principal em `projects/labs-os`. Novos
contratos compartilhados — por exemplo, modelos de serviço, eventos, jobs ou
manifests — devem ser extraídos para cá somente quando houver mais de um
consumidor real.
